Overview <br>
This project is a full-stack inventory management system built using Spring Boot. It enables users to manage parts and products, including creating, updating, deleting, and associating parts with products through a web-based interface.
The application demonstrates enterprise-level concepts such as layered architecture, object-relational mapping, custom validation, and dynamic server-side rendering using Thymeleaf. <br>
Features <br>
-Full CRUD operations for Parts and Products <br>
-Support for: <br>
--In-house parts (internal part ID) <br>
--Outsourced parts (company name) <br>
-Associate and remove parts from products <br>
-Search and filtering for parts and products <br>
-Persistent storage using H2 database <br>
-Custom validation enforcing business rules <br>
-Dynamic UI with real-time updates <br>
-Error handling and confirmation workflows <br>
Tech Stack <br>
-Backend: Java 17, Spring Boot <br>
-Frameworks: <br>
--Spring Web <br>
--Spring Data JPA <br>
--Thymeleaf <br>
--Hibernate <br>
-Database: H2 (file-based persistence) <br>
-Build Tool: Maven <br>
-Testing: JUnit, Mockito <br>
